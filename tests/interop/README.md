# CBOR interoperability

`tests/test_codec.py::test_canonical_cbor_known_vector` asserts the exact deterministic CBOR bytes for the map `{"a": 1, "b": 2}` (`a2 61 61 01 61 62 02`). This is a small cross-implementation guard for canonical map ordering; it is not a complete protocol interoperability suite.

The CI workflow installs the declared `cbor2` dependency from package metadata and runs the full suite without a shim. It also builds the wheel, installs it into a separate virtual environment, and runs the tests outside the source tree to ensure imports resolve to the installed artifact.

Before a stable release, add independent fixtures for signed envelopes, identity documents, and relay traces generated by a second implementation, and test both decode and encode compatibility.
